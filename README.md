# 2주차 구조 수정 기록

## 수정한 내용
`header`의 `nav` 링크(`#about`, `#features`, `#steps`, `#subscribe`)를
각 `section`의 `id`와 연결하고, 제목을 `h1 → h2 → h3` 계층으로 정리했습니다.

## 수정 이유
메뉴를 클릭하면 원하는 섹션으로 바로 이동할 수 있어 필요한 정보를
빠르게 찾을 수 있고, 제목 계층이 명확해져 화면 낭독기 사용자도
내용의 구조를 쉽게 파악할 수 있습니다.

# 3주차 CSS 수정 기록

## 수정한 내용
`.primary-button`에 `:hover`, `:focus`, `:active` 상태별 스타일을 추가하고,
`input[type="email"]:focus`에 outline을 적용했습니다.

## 수정 이유
버튼에 마우스를 올리거나 키보드로 이동했을 때 색이 바뀌고, 클릭 시
살짝 눌리는 효과가 생겨 클릭 가능한 요소임을 바로 알 수 있습니다.
이메일 입력창도 포커스 시 테두리가 강조되어, 키보드만으로 이용하는
사용자도 현재 입력 위치를 쉽게 파악할 수 있습니다.

# 4주차 반응형 수정 기록

## 확인한 문제
390px에서 메뉴(`.site-nav`)가 한 줄로 몰려 좁아지고, 기능 카드
(`.feature-list`)가 지나치게 좁아지며, 구독 폼(`.subscribe-form`)의
입력창과 버튼이 서로 밀렸습니다.

## 수정한 내용
`.site-nav`에 `flex-wrap`을 추가하고, `.feature-list`를
`display: grid`와 `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`로
바꿨습니다. `768px` 이하 미디어 쿼리를 추가해 메뉴·소개 영역·기능 카드·
구독 폼을 한 열로 배치했습니다.

## 달라진 점
1100px·769px·768px·390px 모든 너비에서 가로 스크롤 없이 메뉴, 기능
카드, 이메일 입력창과 버튼을 읽고 조작할 수 있습니다.

# 5주차 JavaScript 피드백 수정 기록

## 수정한 내용
"알림 설정" 영역을 추가하고 `script.js`에서 `#saveButton`에 click
이벤트를 연결했습니다. 클릭하면 `#saveMessage`의 문구와 `is-saved`
클래스, 버튼의 글자와 `disabled` 상태가 함께 바뀝니다.

## 수정 이유
저장 완료를 문구·색·버튼 상태 세 가지로 동시에 보여주면 사용자가
저장이 끝났다는 것을 더 확실히 알 수 있고, 버튼을 비활성화해 같은
동작을 중복 클릭하는 것을 막을 수 있습니다.

# 6주차 이벤트·동적 UI 수정 기록

## 구현한 이벤트
- `click`: `#themeButton`을 누르면 `body`에 `dark` 클래스를 토글해
  밝은/어두운 테마를 전환하고 버튼 문구도 함께 바뀝니다.
- `input`: `#userName`에 글자를 입력·삭제할 때마다 `#userNameCount`에
  현재 글자 수를 `N / 10` 형식으로 즉시 표시합니다.
- `change`: `#agreeCheck` 체크박스를 선택·해제하면 안내 문구
  (`#agreeMessage`), 완료 스타일(`is-ready`), `#startButton`의
  `disabled` 상태가 함께 바뀝니다.
- `click` + `querySelectorAll`/`forEach`: "서비스 정보" 섹션에 탭
  (`#tab-intro`/`#tab-guide`/`#tab-question`)을 만들고, 탭을 클릭하면
  기존 선택을 모두 해제한 뒤 클릭한 탭과 연결된 패널 하나만 보여줍니다.

## 화면 변화
- 테마 버튼 클릭 시 배경·글자·카드 색이 다크 모드로 전환됩니다.
- 닉네임 입력창에 글자를 쓰면 바로 아래 글자 수 안내가 실시간으로
  바뀝니다.
- 체크박스를 선택하면 안내 문구가 완료 스타일(초록 배경)로 바뀌고
  "단어 학습 시작하기" 버튼이 활성화됩니다. 해제하면 원래 상태로
  돌아갑니다.
- 기존에 따로 있던 "서비스 소개"·"이용 방법" 섹션을 "서비스 정보" 탭
  안으로 합치고, "자주 묻는 질문" 탭을 새로 추가했습니다. 기존 기능
  3가지(빠른 암기·맞춤형 단어장·학습 기록 관리)는 "서비스 소개" 탭
  안에 목록으로 그대로 남겨 내용 손실 없이 정리했습니다.

## 테스트 결과
Playwright로 1100px·768px·390px에서 가로 스크롤 없음을 확인했고,
테마 전환·글자 수 표시·체크박스-버튼 연동·탭 전환(3개 모두)을 각각
클릭/입력 이벤트로 직접 실행해 기대한 상태 변화가 모두 일어나는 것을
확인했습니다. 개발자 도구 Console에도 오류가 없었습니다. 다크 모드에서
"알림 설정" 문구, 탭 버튼, 기능 목록의 글자 대비가 낮았던 문제를 찾아
별도 색상을 추가해 수정했습니다.
