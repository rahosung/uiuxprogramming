# 단어장 — 영어 단어 학습 서비스

매일 조금씩, 오래 남는 영어 단어 학습을 돕는 서비스 소개 페이지입니다.

- 배포 주소: https://rahosung.github.io/uiuxprogramming/
- 저장소: https://github.com/rahosung/uiuxprogramming

## 사용자와 목적

- **사용자**: 영어 단어를 꾸준히 외우고 싶지만, 무엇을 얼마나 외울지 스스로
  정하기 어려운 학습자
- **서비스 목적**: 나에게 필요한 단어만 골라 담은 단어장을 만들고, 하루 학습량을
  정해 반복 학습을 시작하게 한다.
- **완료할 핵심 행동**: 이용 안내에 동의한 뒤 단어장 이름·학습 시작일·하루
  학습량을 정하고, 확인 화면에서 내용을 검토해 학습 시작을 완료한다.
- **완료 조건**: "학습 내용 확인" 화면에서 입력한 내용을 검토하고 "학습을
  시작했습니다" 화면에 도달한다.

## 사용자 흐름

1. **진입** — "학습 환경 설정"에서 이용 안내 체크박스를 선택하면 "단어 학습
   시작하기" 버튼이 활성화된다. 버튼을 누르면 학습 시작 흐름이 열린다.
2. **입력** — 단어장 이름과 학습 시작일을 적는다. 둘 중 하나라도 비어 있으면
   다음 단계로 넘어가지 않고 같은 단계에서 고친다.
3. **선택** — 하루에 외울 단어 수(5·10·20개)를 고른다. 10개 이상을 고르면 복습
   부담에 대한 안내가 나타난다.
4. **확인** — 단어장 이름·시작일·하루 학습량을 한 줄 요약으로 검토한다. 틀린
   값은 이전 단계로 돌아가 고치고, 고친 값은 확인 화면에 다시 반영된다.
5. **완료** — 학습 시작 완료 화면을 보여 주고, "다시 만들기"로 처음부터 새
   단어장을 만들 수 있다.

## 인터랙션 시나리오

| 행동 | 이벤트·조건 | 화면 반응과 다음 상태 |
| --- | --- | --- |
| 안내 동의 체크 | `change` · 체크됨 | 안내 문구가 완료 상태로 바뀌고 "단어 학습 시작하기" 버튼이 활성화된다. |
| 학습 시작 버튼 클릭 | `click` · 동의 완료 | 학습 흐름(`#studyFlow`)이 열리고 1단계로 이동해 이름 칸에 포커스된다. |
| 이름·날짜 없이 다음 클릭 | `click` · 필수값 비어 있음 | 비어 있는 칸을 빨간 테두리로 표시하고 무엇을 입력할지 알린 뒤 같은 단계에 머문다. |
| 하루 학습량을 10개 이상으로 변경 | `change` · 10개 이상 | 복습량이 함께 늘어난다는 안내를 표시한다. 5개로 되돌리면 안내가 사라진다. |
| 확인 단계에서 이전 클릭 | `click` · 수정 요청 | 입력값을 유지한 채 이전 단계로 돌아간다. |
| 완료 후 다시 만들기 클릭 | `click` · 초기화 | 입력·오류·선택·진행 표시를 모두 초기화하고 1단계로 돌아간다. |

## 중간고사 추가 기능 — 내 단어장 목록

7주차 흐름의 **끝(학습 시작하기 완료 시점)**에 이어서, 완료할 때마다 만든
단어장이 "내 단어장 목록"에 자동으로 추가되고, 목록에서 다시 열어 내용을
확인하거나 더 이상 필요 없는 단어장을 삭제(취소)할 수 있게 했습니다.

| 사용자 행동 | 확인할 조건 | 반응 | 다음 행동 |
| --- | --- | --- | --- |
| 학습 시작하기 완료 | 목록에 항목이 있는지 | "아직 만든 단어장이 없습니다" 안내가 사라지고 목록에 새 항목(이름·시작일·하루 학습량)이 추가된다. | 목록에서 다른 단어장을 열거나 삭제할 수 있다. |
| 목록 항목의 "열기" 클릭 | 클릭한 항목의 id | 상세 패널에 그 단어장의 이름·시작일·하루 학습량이 그대로 반영되어 표시된다. | "닫기"로 상세 패널을 닫을 수 있다. |
| 목록 항목의 "삭제" 클릭 | 클릭한 항목의 id | 목록에서 해당 항목이 사라진다(완료한 선택 취소). 지금 열어 보던 항목을 삭제하면 상세 패널도 함께 닫힌다. | 남은 항목을 계속 조작하거나 새로 학습을 시작할 수 있다. |
| 마지막 항목까지 삭제 | 목록 길이가 0인지 | 목록이 비어 "아직 만든 단어장이 없습니다. 학습을 시작하면 여기에 추가됩니다." 안내로 되돌아간다(결과 없음 상태). | "단어 학습 시작하기"로 새 단어장을 추가할 수 있다. |

### 테스트한 결과

- **정상**: 학습 시작을 두 번 완료하니 목록에 항목이 2개로 늘어났습니다.
- **열기**: 각 항목의 "열기"를 누르면 상세 패널에 그 항목의 이름·시작일·
  학습량이 정확히 표시됐습니다.
- **삭제(취소)**: 상세 패널로 열어 둔 항목을 삭제하면 목록에서 빠지는 동시에
  상세 패널도 자동으로 닫혔습니다.
- **결과 없음**: 남은 항목을 모두 삭제하니 처음과 같은 "아직 만든 단어장이
  없습니다" 안내로 돌아갔습니다.
- **모바일**: 1100px·768px·390px 모두 가로 스크롤이 없었고, 768px 이하에서는
  목록 항목과 열기·삭제 버튼이 세로로 배치되어 잘리지 않았습니다.
- **콘솔**: 전체 경로(추가·열기·삭제·빈 상태 복귀)를 실행하는 동안 오류가
  없었습니다.

## 테스트 결과

브라우저(Chromium)에서 각 경로를 직접 조작해 확인했습니다.

- **정상 경로**: 동의 → 시작 → 이름·날짜 입력 → 학습량 선택 → 확인 → 완료까지
  끊김 없이 이어졌고, 진행 표시가 `1 / 3` → `2 / 3` → `3 / 3` → `학습 시작 완료`로
  바뀌었습니다.
- **빈 입력**: 이름과 날짜가 모두 빈 상태에서는 "단어장 이름을 입력해 주세요."를
  보여 주며 1단계에 머물렀고, 이름만 채우면 "학습 시작일을 선택해 주세요."로
  안내가 바뀌며 날짜 칸으로 포커스가 이동했습니다.
- **이전·수정**: 3단계에서 2단계, 2단계에서 1단계로 돌아가도 입력한 이름·날짜·
  학습량이 그대로 남아 있었고, 이름을 고친 뒤 다시 확인하면 요약 문구에 고친
  값이 반영됐습니다.
- **다시 시작**: 이름·날짜가 비워지고 학습량이 5개로, 복습 안내와 요약 문구,
  오류 표시가 모두 초기 상태로 돌아갔습니다.
- **모바일**: 1100px·768px·390px에서 가로 스크롤이 없었고, 레이블·입력창·버튼·
  오류 문구가 잘리지 않았습니다. 768px 이하에서는 버튼이 한 열로 배치됩니다.
- **콘솔**: 전체 경로를 실행하는 동안 오류가 없었습니다.

## 주차별 수정 기록

### 2주차 — 구조

`header`의 `nav` 링크를 각 `section`의 `id`와 연결하고, 제목을 `h1 → h2 → h3`
계층으로 정리했습니다. 메뉴를 클릭하면 원하는 섹션으로 바로 이동할 수 있고,
제목 계층이 명확해져 화면 낭독기 사용자도 구조를 쉽게 파악할 수 있습니다.

### 3주차 — CSS

`.primary-button`에 `:hover`, `:focus`, `:active` 상태별 스타일을 추가하고,
`input[type="email"]:focus`에 outline을 적용했습니다. 클릭 가능한 요소임이
분명해지고, 키보드만으로 이용하는 사용자도 현재 위치를 알 수 있습니다.

### 4주차 — 반응형

`.site-nav`에 `flex-wrap`을 추가하고 기능 목록을 자동 Grid로 바꿨습니다.
`768px` 이하 미디어 쿼리를 추가해 메뉴·소개 영역·카드·폼을 한 열로 배치했고,
1100px·769px·768px·390px에서 가로 스크롤 없이 조작할 수 있습니다.

### 5주차 — JavaScript 피드백

"알림 설정" 영역의 `#saveButton`에 click 이벤트를 연결해, 클릭하면 문구와
`is-saved` 클래스, 버튼 글자와 `disabled` 상태가 함께 바뀌도록 했습니다.
저장 완료를 세 가지 단서로 동시에 보여 주고 중복 클릭을 막습니다.

### 6주차 — 이벤트와 동적 UI

`click`(테마 전환), `input`(닉네임 글자 수), `change`(동의 체크) 이벤트를
각각 연결하고, `querySelectorAll`과 `forEach`로 "서비스 정보" 탭 3개를
구현했습니다. 기존에 따로 있던 소개·이용 방법 섹션을 탭 안으로 합치고
자주 묻는 질문을 추가했습니다.

### 7주차 — 사용자 흐름

기존 "단어 학습 시작하기" 버튼(동의 조건 유지)을 진입점으로 삼아 입력 →
선택 → 확인 → 완료의 3단계 흐름을 추가했습니다. 필수값 검증, 이전 단계
이동 시 값 유지, 완료 후 초기화 경로를 함께 구현했습니다.

### 중간고사 — 내 단어장 목록

7주차 흐름의 완료 시점에 이어서 "내 단어장 목록"을 추가했습니다. 학습
시작을 완료할 때마다 목록에 항목이 쌓이고, 각 항목을 열어 상세 내용을
보거나 삭제(취소)할 수 있습니다. 모두 삭제하면 결과 없음 안내로 돌아갑니다.
자세한 인터랙션 시나리오와 테스트 결과는 위 "중간고사 추가 기능" 절을
참고하세요.
